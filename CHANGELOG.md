# Changelog

## 0.1.0 - first release

- Jalali (Shamsi) calendar: `JalaliDate`, `format_jalali`, parsing, arithmetic.
- Persian/Arabic digit conversion, Arabic-letter normalisation, thousands separators.
- Validators: national ID (کد ملی), mobile, bank card (Luhn), Sheba/IBAN, postal code.
- Form fields, model fields and a `JalaliDateField` form field.
- Template filters: `jalali`, `persian_digits`, `english_digits`, `fa_intcomma`, `number_words`; tag `jalali_now`.
- Number to Persian words.
- Persian translation of all messages.
